# Public page design concepts

These are visual concepts for the landing, login, and signup pages. They are not
implemented screens or final brand assets.

| Page | Concept |
| --- | --- |
| Landing | [landing.png](landing.png) |
| Login | [login.png](login.png) |
| Signup | [signup.png](signup.png) |

The concepts carry the dashboard's charcoal surfaces, light typography, thin
lavender accents, and requirement-to-review thread into the public pages. The
landing page uses a single example evidence path as its product demonstration.
Login and signup show only the existing GitHub sign-in route; they do not propose
email/password authentication. The illustrated thread symbol is conceptual;
implementation should use the existing `app/web/public/thread-mark.png` asset.

The images were generated with the built-in image tool. The landing concept was
refined once to remove extra status chips and activity panels. Select or revise
the visual direction before changing the frontend.
