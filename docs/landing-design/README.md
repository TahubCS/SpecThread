# Public page design concepts

These are visual concepts for the landing, login, and signup pages. The simpler
version 2 set guided the implemented public layouts; the original images remain
here for comparison. The images are references, not exact UI specifications.

| Page | Current concept | Original |
| --- | --- | --- |
| Landing | [landing-v2.png](landing-v2.png) | [landing.png](landing.png) |
| Login | [login-v2.png](login-v2.png) | [login.png](login.png) |
| Signup | [signup-v2.png](signup-v2.png) | [signup.png](signup.png) |

The concepts carry the dashboard's charcoal surfaces, light typography, thin
lavender accents, and requirement-to-review thread into the public pages. The
landing page uses a single example evidence path as its product demonstration.
Login and signup concepts show only GitHub sign-in. The implemented pages also
include email/password and Google, as required by ADR-016. The illustrated thread
symbol is conceptual; the application uses `app/web/public/thread-mark.png`.

The images were generated with the built-in image tool. The landing concept was
refined once to remove extra status chips and activity panels.

Version 2 reduces the landing headline, removes the lower feature columns and
the boxed evidence nodes, and treats the evidence path as one light row. The auth
pages use smaller copy and buttons with a quiet evidence path instead of a large
split-screen illustration.
